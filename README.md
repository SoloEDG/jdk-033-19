## 旧海图校勘

点击竞速栏的「旧图校勘」，或在「航行记录」中选择旧档航次：

- 赛道 `07`：按编号匹配存档旧图，可在旧图与新版图上成对标记固定岸物；示例中第 5 对岸物为疑似错配。工作台会把航迹分为「确能定位」和「仍有多个位置解释」两段，并在新版图上叠加另一种投影解释。
- 赛道 `12`：找不到同号底图，只提供原坐标轨迹、擦标原始距离和旧裁判记录，并明确标记「无法投影」。
- 拖动校勘时间轴到擦标点时，可同时查看新版投影坐标和船到旧标的原始距离；总成绩始终读取旧裁判卡的时长与罚时，不会按投影轨迹重算。
